# Дорожная карта

Статусы: ✅ сделано, 🚧 в работе, ⏳ запланировано.

## v1 (текущее состояние)

* ✅ Ретранслятор на белом IP: UDP и TCP на одном порту, `-udp`/`-tcp`/`off`
* ✅ Изолированные сети «по имени и паролю» (аналог Radmin VPN rooms)
* ✅ Автоматические адреса в `26.x.x.x`, `/24` на сеть
* ✅ Явный выбор транспорта клиентом (`-transport udp|tcp`), проверка на сервере
* ✅ Смешивание транспортов в одной сети (UDP-клиент ↔ TCP-клиент)
* ✅ AES-256-GCM, X25519, PBKDF2-SHA256, HMAC-аутентификация, сквозная проверка
* ✅ Список участников, keepalive, таймауты, реконнект с экспоненциальной паузой
* ✅ Админ-API: статистика, предсоздание сетей, kick с баном
* ✅ Режим интернет-шлюза (`-internet` + `-gateway`, NAT)
* ✅ Юнит- и интеграционные тесты, e2e на network namespaces (UDP+TCP+изоляция+NAT)
* ✅ Сборка под Windows/Linux/macOS x64/arm64/armv7 в GitHub Actions

## v1.1 — эксплуатация

* ⏳ Пакеты: `.deb`, `.rpm`, MSI, домашний репозиторий
* ⏳ `cslvpn client -config /etc/cslvpn.yaml` — конфиг-файл вместо флагов
* ⏳ Метрики Prometheus (`/metrics`) + healthcheck для systemd/Docker
* ⏳ Rate limiting рукопожатий и защита от перебора паролей (сейчас PBKDF2
  делает перебор дорогим, но лимитов на попытки нет)
* ⏳ Ротация пароля сети без пересоздания (смена ключа, рассылка `KEY_ROTATE`)

## v1.2 — производительность

* 🚧 Батчинг UDP-датаграмм (несколько кадров в одной) — экономия на заголовках
* 🚧 `SO_REUSEPORT` и несколько воркеров на сервере
* ⏳ Оптимизация копирований в горячем пути (кэш буферов на сессию)
* ⏳ Опциональный `crypto/aes` + GCM на ARM (крипто-ускорение)
* ⏳ Нагрузочный тест (iperf3 через туннель) в CI, отчёты по Мбит/с

## v2 — ближе к Radmin VPN по возможностям

* ⏳ **Прямой P2P-канал (UDP hole punching)** с ретранслятором как fallback:
  сигнализация кандидатов через сервер, метки «direct/relay» в статусе.
  Протокол уже содержит место под это (`PEER_FLAG_INITIATOR`,
  `HELLO.nonce`).
* ⏳ **L2-эмуляция / широковещание** (ARP, DHCP-подобное обнаружение) для игр,
  которым нужен broadcast; режим `-l2`.
* ⏳ **Windows-клиент с Wintun** из коробки (см. `docs/WINDOWS.md` §2.3),
  включая автонастройку адреса/маршрутов и интернет-режим.
* ⏳ **GUI**: трей-приложение (создать/войти в сеть, список участников,
  графики трафика).
* ⏳ Мобильные клиенты (Android/iOS) — нужен VPN-сервис на стороне ОС.
* ⏳ Управление доступом: роли в сети (админ/участник), белый список адресов.

## v3 — масштаб и доверие

* ⏳ Федерация ретрансляторов (несколько точек входа, выбор ближайшей).
* ⏳ Identity для устройств (ключи вместо общего пароля) с сохранением
  «имя+пароль» режима для простых сетей.
* ⏳ Аудит безопасности: внешний обзор протокола, публикация threat model.
* ⏳ Полностью независимая реализация протокола (Rust/C) для проверки
  спецификации на совместимость.

## Как принять участие

Каждый пункт — отдельный issue с меткой `roadmap`. Перед крупными изменениями
протокола обновляйте `docs/PROTOCOL.md` и добавляйте тест в
`internal/relay/relay_test.go`.
